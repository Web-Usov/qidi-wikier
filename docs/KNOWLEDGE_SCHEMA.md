# Схема знаний

## Кандидат доказательства

Автоматический слой версии 0.4.1. Кандидат не считается подтверждённым фактом до редакторской проверки.

```json
{
  "schemaVersion": 2,
  "id": "EVIDENCE-QIDI-COMMON-CHAT-593285",
  "threadId": "THREAD-QIDI-COMMON-CHAT-593285",
  "rootId": 593285,
  "topic": "firmware-errors",
  "messageIds": [593285, 593287],
  "authors": ["User"],
  "kinds": ["question", "observation", "answer", "recommendation"],
  "status": "ready",
  "provisionalReliability": "D",
  "knowledgeValue": 0.82,
  "technicalScore": 12,
  "entities": {
    "materials": ["ABS"],
    "printers": ["QIDI-Q2"],
    "components": ["chamber", "cooling", "firmware-config"]
  },
  "parameters": [
    { "kind": "temperature", "value": "камера 60", "messageId": 593285 }
  ],
  "flags": ["needs-editorial-verification", "answer-not-validated"],
  "sourceExcerpt": "[593285] ..."
}
```

### Типы содержимого

- `question` — вопрос или запрос диагностики;
- `observation` — техническое наблюдение или измерение;
- `answer` — содержательный ответ внутри точной reply-цепочки, включая короткие ответы и наборы параметров;
- `recommendation` — предлагаемый шаг или настройка;
- `result` — явно описанный исход проверки, а не простое употребление слов «результат», «получается» или «решил»;
- `configuration` — конфигурация, макрос или фрагмент G-code;
- `reference` — внешняя ссылка.

### Статусы кандидата

- `ready` — есть содержательный ответ, результат, рекомендация или конфигурация, пригодные для редакторской проверки;
- `question-only` — в точной цепочке отсутствует содержательный ответ;
- `needs-context` — наблюдение недостаточно закончено;
- `reference-only` — содержание в основном находится по внешней ссылке.

Вопросительные знаки и процентные последовательности внутри URL не участвуют в определении вопросов и параметров.

### Предварительная надёжность

- `C` назначается только подробному собственному результату «до/после»: автор исходного случая сам описал последующую проверку, сохранились параметры и технические сущности, а ключевое медиа не отсутствует;
- `D` назначается коротким ответам, чужому опыту, одиночным измерениям, рекомендациям, ссылкам и незавершённым случаям.

### Флаги

- `needs-editorial-verification` — обязательный флаг каждого кандидата;
- `single-message` — точная цепочка состоит из одного сообщения;
- `media-not-inspected` — у сообщения есть фото или видео, не проанализированное конвейером;
- `ai-generated-or-copied-claim` — текст ссылается на нейросеть или выглядит как скопированный ответ;
- `commerce-reference` — в цепочке обнаружена торговая или товарная ссылка;
- `missing-answer` — содержательный вопрос без ответа;
- `external-reference-only` — утверждение нельзя оценить без открытия ссылки;
- `insufficient-context` — наблюдение не является законченным техническим случаем;
- `answer-not-validated` — ответ найден, но в цепочке нет собственного подтверждённого результата;
- `has-unverified-context-edges` — рядом есть эвристические связи, которые ещё не подтверждены.

Короткие бессодержательные фрагменты без сущностей, параметров, конфигурации, ссылки или описанного результата не попадают в список кандидатов, даже если их исходный `knowledgeValue` достиг порога.

## Проверенное доказательство

После редакторской проверки кандидат переносится в отдельный слой доказательств. Редактор должен:

- подтвердить соответствие сообщений одному техническому случаю;
- проверить, что найденный ответ действительно отвечает на исходный вопрос;
- убрать неверно извлечённые параметры и сущности;
- проверить наличие результата;
- отметить противоречия;
- присвоить окончательную надёжность;
- сохранить ссылку на точную цепочку.

## Карточка знания

```markdown
## ABS-EXOFLEX-001 — Exoflex ABS

- Категория: Филаменты / ABS / Производители
- Оборудование: QIDI Q2; другие закрытые принтеры
- Период данных: 2025-05 — 2026-07
- Надёжность: B
- Статус: противоречиво
- Последняя проверка: 2026-08-05

### Краткий вывод

Завершённая формулировка без скрытых допущений.

### Подтверждённые наблюдения

- Наблюдение с понятным основанием.

### Противоречия и ограничения

- Что не удалось подтвердить.

### Практические действия

1. Конкретный шаг.

### Доказательства

- `THREAD-QIDI-FILAMENT-349336`
```

## Уровни надёжности

| Уровень | Значение |
|---|---|
| A | Официальный документ, измерение или воспроизводимый тест |
| B | Несколько независимых пользователей получили одинаковый результат |
| C | Один подробный собственный опыт с параметрами и явно описанным результатом |
| D | Непроверенное предположение, общий совет, чужой опыт или незавершённый случай |
| X | Опровергнуто или устарело |

Автоматический конвейер может назначить только **предварительные** `C` и `D`. Окончательный уровень присваивается редактором.

## Статусы карточек

- `актуально`
- `зависит от прошивки`
- `противоречиво`
- `требует проверки`
- `устарело`

## Обязательные поля доказательства

- стабильный ID точной Telegram-цепочки;
- имя исходной выгрузки;
- ID сообщений и даты;
- дословно сохранённые параметры;
- извлечённые материалы, принтеры, компоненты и бренды;
- `knowledgeValue` исходных сообщений;
- краткий редакторский вывод;
- указание на отсутствующие медиа или контекст.

## Использование контекстного графа

Предположительное ребро не является доказательством само по себе. Оно используется только для поиска соседнего контекста. Перед включением связанного сообщения в доказательство редактор должен подтвердить, что оба сообщения относятся к одному случаю.

Карточка знания всегда ссылается на точные цепочки. Контекстные рёбра можно указывать дополнительно как проверенный переход между цепочками.
