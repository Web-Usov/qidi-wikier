# QIDI Wikier

Инструменты для превращения Telegram-чатов о QIDI Q2, QIDI BOX и филаментах в проверяемую базу знаний.

## Что делает версия 0.3

- потоково читает большие Telegram Desktop JSON без загрузки файла целиком в память;
- удаляет очевидный флуд, объявления, сервисные сообщения и пустые медиа;
- сохраняет точные цепочки через `reply_to_message_id`;
- распознаёт служебные ID форумных топиков Telegram;
- извлекает материалы, принтеры, компоненты, симптомы и бренды;
- строит отдельный граф предположительных связей между верхнеуровневыми сообщениями;
- не склеивает предположительные связи в Telegram-цепочки и не допускает каскада ошибок;
- отклоняет неоднозначные связи, если лучший кандидат мало отличается от второго;
- рассчитывает отдельную оценку `knowledgeValue`;
- формирует стратифицированную выборку связей `low / medium / high` для ручной проверки;
- создаёт Markdown-пакеты, статистику, карантин и отчёт об удалении.

## Требования

- Node.js 22.6 или новее;
- исходные Telegram JSON на локальном диске.

Внешние npm-зависимости не используются. `npm install` не обязателен.

## Быстрый старт

```bash
mkdir -p sources prepared
cp /путь/к/qidi_common_chat.json ./sources/

npm run ingest -- \
  --input ./sources/qidi_common_chat.json \
  --output ./prepared/common \
  --source-name qidi_common_chat
```

Дополнительные параметры:

```text
--max-chars 600000
--context-window-minutes 12
--same-author-window-minutes 45
--min-context-score 4.0
--min-score-margin 0.75
--review-sample-size 120
```

`--min-score-margin` задаёт минимальный отрыв лучшего кандидата от второго. Связь не создаётся, когда несколько соседних сообщений подходят почти одинаково.

## Результат

```text
prepared/common/
├── manifest.json
├── statistics.json
├── chunks/
│   ├── qidi_common_chat_001.md
│   └── ...
├── quarantine/
│   └── uncertain_messages.jsonl
├── review/
│   ├── context_graph.jsonl
│   └── context_links_sample.md
└── skipped/
    └── removal_report.json
```

В `chunks` находятся только точные Telegram reply-цепочки. Предположительные связи перечисляются как метаданные, но не добавляют чужой текст внутрь цепочки.

`context_links_sample.md` содержит выборку из трёх уровней уверенности, а не только самые слабые связи.

## Ограничения

- Алгоритм не определяет истинность технических советов.
- Отсутствующие фотографии и видео не анализируются.
- Граф связей остаётся эвристическим и требует выборочного аудита.
- Подготовленный корпус — слой доказательств, а не готовая энциклопедия.
- Следующий этап — генерация кандидатов в карточки знаний с обязательными ссылками на доказательства.
